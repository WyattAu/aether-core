Class HttpClient

Capability-guarded HTTP client for actor use.

Requires Capability.NETWORK_OUTBOUND to be present in the provided capability set. All requests are subject to a configurable timeout.

Example

const client = new HttpClient(capabilities, 15000);

// GET request
const res = await client.get('https://api.example.com/data');
console.log(res.status, res.body);

// POST request
const postRes = await client.post(
  'https://api.example.com/items',
  { name: 'widget' },
  { 'X-Custom-Header': 'value' }
);
