Class StateHandle

In-memory key-value store for actor state.

Each actor owns a StateHandle instance that provides asynchronous access to string-keyed state entries. Data is stored internally as Buffer values, with convenience methods for strings and JSON.

Example

const state = new StateHandle();

// Store a JSON object
await state.setJSON('config', { theme: 'dark', lang: 'en' });

// Retrieve it later
const config = await state.getJSON<{ theme: string; lang: string }>('config');

// List all keys with a prefix
const keys = await state.list('user:');
