Class BackpressureController<T>

Backpressure Controller

Controls the flow of events through the stream processor using one of several strategies. Monitors buffer fill levels against high/low watermarks and invokes callbacks on state transitions.

Example

const controller = new BackpressureController({
  strategy: BackpressureStrategy.Buffer,
  bufferSize: 10000,
});

if (controller.tryPush(event)) {
  // Event accepted
}

if (controller.isOverloaded) {
  // Signal upstream to slow down
}

tryPush

  • tryPush(event: StreamEvent<T>): boolean

    Try to push an event into the buffer.

    Behavior depends on the configured strategy:

    • Buffer: Rejects (returns false) when full.
    • Drop: Drops the event (returns false) when full.
    • Fail: Throws BufferFullError when full.
    • Latest: Evicts the oldest event to make room.

    Parameters

    • event: StreamEvent<T>

      The stream event to buffer.

    Returns boolean

    true if the event was accepted, false if dropped/rejected.

    Throws

    BufferFullError If strategy is Fail and buffer is full.
