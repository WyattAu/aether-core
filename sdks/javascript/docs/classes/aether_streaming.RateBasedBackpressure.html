Class RateBasedBackpressure

Rate-based backpressure controller.

Monitors the rate of events being processed and applies backpressure when the rate exceeds a configured threshold. Includes a cooldown period after backpressure is activated.

Example

const rateBP = new RateBasedBackpressure(1000, 10.0, 1.0);
// Max 1000 events per 10-second window, 1-second cooldown

if (await rateBP.tryAcquire()) {
  await processEvent(event);
}
