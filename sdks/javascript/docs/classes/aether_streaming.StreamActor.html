Class StreamActor<K, V>Abstract

Stream Actor

Base class for stream processing actors that extends the core Actor with event-time processing, watermark tracking, windowed aggregation, backpressure handling, and typed streaming state.

Example

class MyStreamProcessor extends StreamActor<string, Event> {
  static get name(): string {
    return 'my_stream_processor';
  }

  async processEvent(event: StreamEvent<Event>): Promise<void> {
    const data = event.value;
    await this.emitValue('output', transform(data));
  }
}

Type Parameters

  • K = string

    The key type for partitioning (default: string).

  • V = unknown

    The event payload type (default: unknown).
